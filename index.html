About Me

Fullstack Developer.
Frontend, Backend, Production.

My name is Joan Gueffroy. I am a fullstack web developer based in Butiá, Brazil. I design and ship complete products: the interface people use, the APIs and services behind it, the data layer, and the deployment that keeps it running. I started in 2004 writing PHP and HTML at a small software house, and I have spent the years since working across the stack — not only on one layer of the application.

A typical project for me covers both sides of the product. I build component-based frontends in React, Next.js, or Vue, then connect them to Node.js, Django, Laravel, or Spring Boot services. I model data in PostgreSQL or MySQL, add caching with Redis when it matters, and containerise the result so it can be deployed with CI/CD. I care about how the code reads to the next developer and how the product feels to the person using it.

I have worked in agencies, product teams, and as an embedded contractor. Agencies taught me to move quickly and talk clearly with clients. Product work taught me ownership of a feature from ticket to production. Larger systems taught me how to keep a codebase maintainable as traffic and team size grow. I still write production code every week — architecture and reviews sit on top of that, not instead of it.

Most recently I have been the lead fullstack engineer on a multi-tenant SaaS platform: React on the client, Node.js microservices and PostgreSQL on the server, Docker and AWS in production. I work remotely from Brazil and take on selected consulting engagements when the problem is a good fit. I am open to fullstack roles that need someone who can own a feature end to end.

Away from the keyboard I read, photograph urban landscapes, and mentor junior developers. Teaching someone how a request travels from a button click through an API into a database — and back — is still one of the most useful things I do.

FinanceTrack Dashboard

An internal analytics and reporting platform developed for a Warsaw-based financial advisory firm, giving their analysts real-time visibility into portfolio performance, client metrics, risk indicators, and regulatory compliance status. The frontend was built in Vue.js with a suite of custom interactive data visualisation components. The backend aggregated live data from multiple third-party financial data APIs through a secure Python service layer with robust retry and fallback logic. 03

SmartConnect IoT Portal

A browser-based management portal for an IoT hardware company, allowing their clients to monitor the status of thousands of connected devices, configure alert thresholds, view historical sensor data, and manage firmware update schedules. The platform processes several thousand data points per minute and uses persistent WebSocket connections to push live updates into the interface without requiring a page refresh. The backend was built in Node.js, with a time-series-optimised storage layer to handle the volume and velocity of device telemetry. The project also involved a mobile-first responsive redesign, since field engineers needed to use the portal on tablets in industrial environments.

React Node.js WebSockets MongoDB Kubernetes GCP

04

CloudNest File Management System

A secure, self-hosted file management and collaboration application built for a Warsaw law firm that required an on-premises alternative to commercial cloud storage services due to client data confidentiality requirements. The system supports drag-and-drop uploads of files up to several gigabytes, folder hierarchies, granular per-user and per-folder sharing permissions, full-text document search via Elasticsearch, version history, and a complete audit trail of all access and modification events. Security was a primary concern throughout: the implementation includes end-to-end encryption at rest, two-factor authentication, session management, and detailed access logs reviewed by the firm's compliance team monthly.

React Django Elasticsearch PostgreSQL Docker Nginx
